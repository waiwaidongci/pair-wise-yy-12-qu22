# hxyfront-62011 蹄铁师安全派工台

源提示词编号：6

面向马术俱乐部蹄铁师的安全派工工作台。蹄铁师上门前只看到马号，到了马房才发现马不肯抬蹄、踢人或需要搭档按住——本工具把风险信息前置到派工环节：

- 每匹马登记抬蹄习惯、踢人次数和配合评分
- 高风险马只能排双人时段
- 同一匹马当天只留一张未完成派工单
- 一次安全修蹄记一次配合，连续两次达到 4 分自动降为普通
- 改动风险或取消派工，原安排失效并重新待排
- 数据保存在浏览器 localStorage

## 代码分层

- `src/store.ts` —— 记录层：数据类型与 localStorage 持久化
- `src/rules.ts` —— 判断层：派工规则与风险判定（纯函数）
- `src/App.tsx` —— 页面层：渲染与交互

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
```
